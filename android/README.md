# Metacritic 游戏评分 · Android v1.8

开发者：**南仙**

把 DSH 的 Metacritic 游戏评分插件完整搬到安卓：内置全量快照，支持 **App 内实时抓取、全量重建、批量翻译、详情页平台评分与评分分布默认展示**，翻译只使用 **Bing**，不含任何 DeepSeek / 大模型翻译。筛选与排序交互与 DSH 插件保持同步。

## 安装

1. 把 `Metacritic-南仙-v1.8.apk` 传到手机。
2. 点开 APK，允许「安装未知来源应用」。
3. 桌面出现「Metacritic 游戏评分」图标。

- 系统要求：**Android 12.0（API 31）及以上**（minSdk 31，targetSdk 31）
- 安装包约 3.4 MB，签名证书 `CN=NanXian, O=NANXIAN`
- 覆盖升级：可直接覆盖安装旧版本，数据保存在应用私有目录，不会丢

## 本次更新（v1.8）

- **排序改为 Material 3 弹层**：列表里的「排序」现在是一个字段框，点开底部弹层选「评分最高 / 评分最低 / 名称排序」，不再使用原生下拉框。
- **年份起止改为 Material 3 年份选择器**：点「年份」打开弹层，左右两列可滚动年份（开始 / 结束各一列），点选即更新，另有快捷区间；不再使用两个原生下拉框，并会自动滚动到当前选中的年份。
- **发行商移到信息行**：详情页的「发行商」不再放在上架平台卡片底部，而是与发行日期、评级、类型并排显示在标题下方。
- **平台筛选与 Metacritic 官网一致**：平台成员与「平台版本年份」来自官网平台筛选页索引，不再只按列表卡片的主平台判断，多平台游戏不会再漏。
- **更多菜单**：首页右上角主题按钮旁新增「⋯」，点击后屏幕中间弹窗，含「检查更新」「GitHub 仓库」两个按钮（样式与「实时抓取」一致）。
- **检查更新**：读取 GitHub Releases 最新版本，有新版本时可查看说明并前往下载。
- **GitHub 入口**：首页「GitHub 仓库 ↗」直接打开项目仓库。
- **筛选条件记忆**：搜索、年份范围、平台多选、排序会保存，退出 App 重开后自动恢复。
- **详情页刷新**：新增「刷新数据」按钮，强制重抓详情与平台评分分布。
- 与 DSH 插件同步：年份单框、平台多选、排序去掉按年份两项。

## 功能（与 Web 插件对齐）

- **实时抓取（增量）**：只刷新最近两年 + 从未抓过的年份；只追加/更新，不删除已有游戏；有进度条与断点检查点。
- **全量重建**：重爬 1995–当前年份全部列表页（约 620 页，建议 Wi-Fi）。
- **批量翻译**：对当前筛选下未翻译的游戏名调用 Bing 批量翻译，带进度；结果持久化。
- **游戏列表**：封面、中英双语、发行日期、平台、评分徽章（0–49 红 / 50–79 黄 / 80–94 绿 / 95+ 动态金）；年份范围、平台多选、3 种排序、搜索、分页加载。
- **详情页**：海报、Metascore、用户评分、发行日期、评级、类型、**发行商**（与发行信息同排）、开发商；**各平台媒体评分与媒体数，且每个平台的评分分布默认直接展示**（0–49 / 50–79 / 80–99 / 100）；**「翻译简介（Bing）」**；跳转 Metacritic。
- **双主题**：浅色 / 炫彩霓虹，选择记忆。
- **持久化**：抓取结果、翻译缓存、详情缓存写入 App 私有目录 `state.json`，重启即恢复。

- Material You 动态取色（读取 `system_accent1_500` 作为主色）
- Material 3 底部弹层、字段、Filter Chip、复选框
- 状态栏/导航栏图标随主题切换明暗

## 数据与网络

- 首次启动使用打包快照（14,440 款）；之后可用「实时抓取」或「全量重建」更新。
- 列表、筛选、详情基础信息离线可用；抓取、封面、翻译、外链需要联网。
- 数据来源 Metacritic，评分版权归 Metacritic 所有；翻译由 Bing 提供。
